# *Guía de Instalación para Windows*

## *1 Abrir PowerShell como Administrador*

***Abre una terminal de PowerShell con permisos de administrador.***

## *2 Ejecutar los scripts*

***Desde la raíz del proyecto, ejecuta los siguientes comandos:***

```powershell
./windows/01-system.ps1
./windows/02-verify.ps1
./windows/03-update.ps1 # opcional
./windows/04-vscode.ps1
```

## *3 Verificar la instalación*

***Después de ejecutar los scripts, confirma que todo quedó correctamente configurado.***

## *4 Notas*

- ***Ejecuta los scripts en el orden indicado.***
- ***Si aparece un aviso de ejecución de scripts, acepta la ejecución en PowerShell.***
- ***El paso de actualización es opcional, pero recomendado para mantener el sistema actualizado.***
