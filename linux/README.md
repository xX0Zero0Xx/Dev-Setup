# *Guía de Instalación para Linux*

## *1 Dar permisos necesarios a cada archivo*

***Desde la raíz del proyecto, ejecuta el siguiente comando:***

```bash
chmod -R +x linux/
```

## *2 Ejecutar los scripts*

***Luego, ejecuta los scripts en el orden indicado:***

```bash
sudo ./linux/01-sistema.sh
sudo ./linux/02-verificar.sh
sudo ./linux/03-actualizar.sh # opcional
sudo ./linux/04-VS\ Code.sh
```

## *3 Verificar la instalación*

***Después de ejecutar los scripts, confirma que todo quedó correctamente configurado.***

## *4 Notas*

- ***Ejecuta los scripts en el orden mostrado.***
- ***El paso de actualización es opcional, pero recomendado.***
- ***Si tu sistema solicita permisos, autoriza la ejecución con `sudo`.***
